## Обзор

**AI in Digital Medicine** — учебный репозиторий, сопровождающий учебник по искусственному интеллекту и машинному обучению в современной медицине.
Здесь собраны компактные Python-шаблоны и демонстрационные наборы данных для практической работы с биомедицинскими сигналами, метриками сегментации медицинских изображений, поиском по клиническим текстам, нейрофизиологическими данными и молекулярным скринингом.

Репозиторий рассчитан прежде всего на **студентов-медиков, ординаторов, врачей и преподавателей**, которые только начинают работать с методами ИИ и хотят понимать не только то, как запускается код, но и **что означает полученный результат в клиническом смысле**.

---

## Важное предупреждение

> [!CAUTION]
> Репозиторий предназначен **исключительно для учебных целей**.
> Код и данные — демонстрационные материалы. Их нельзя использовать для постановки диагноза, назначения лечения, прогнозирования, сортировки пациентов, принятия клинических решений или валидации клинических систем ИИ.

Все включённые в репозиторий наборы данных являются синтетическими или демонстрационными. Если в преподавании используются реальные клинические данные, они должны быть надлежащим образом обезличены и обрабатываться в соответствии с институциональными, этическими и правовыми требованиями.

## Учебные модули

| Модуль | Тема | Шаблон кода | Основной навык |
|:---:|---|---|---|
| 01 | Визуализация ЭКГ-сигнала | `code/01_ecg_visualization.py` | Чтение и построение графиков биомедицинских сигналов |
| 02 | Классификация ЭКГ | `code/02_ecg_classification.py` | Интерпретация матрицы ошибок, чувствительности, специфичности, F1-меры и ROC-AUC |

## Структура репозитория

```text
AI-in-Digital-Medicine/
├── assets/                 # визуальные материалы для README
├── code/                   # Python-шаблоны для практических заданий
├── data/                   # синтетические и демонстрационные данные
│   ├── ecg/                # ЭКГ-сигналы и таблица признаков ЭКГ
│   ├── eeg/                # примеры ЭЭГ-сигналов
│   ├── segmentation/       # истинные и предсказанные бинарные маски
│   ├── nlp/                # синтетические фрагменты клинических текстов
│   └── molecules/          # демонстрационная таблица молекул
├── docs/                   # методические материалы и описания заданий
├── notebooks/              # опциональные версии для Jupyter / Colab
├── requirements.txt        # минимальные Python-зависимости
└── README.md
```

## Быстрый старт

### 1. Склонируйте репозиторий

```bash
git clone https://github.com/MyProfile-projects/AI-in-Digital-Medicine.git
cd AI-in-Digital-Medicine
```

### 2. Создайте виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate      # macOS / Linux
# .venv\Scripts\activate       # Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Запустите шаблон

```bash
python code/01_ecg_visualization.py
```

## Рекомендуемая методика занятия

1. Начните с клинической задачи: **на какой вопрос мы пытаемся ответить?**
2. Откройте соответствующий набор данных и обсудите его структуру.
3. Запустите шаблон кода.
4. Совместно интерпретируйте результат.
5. Обсудите ограничения, возможные источники ошибок и клиническую безопасность.
6. Попросите студентов написать короткое заключение на медицинском языке.

Цель курса — не программирование с нуля, а понимание связи: **данные → алгоритм → метрика → клиническая интерпретация → ограничение**.

## Минимальные системные требования

- Python 3.10 или выше
- Jupyter Notebook или Google Colab (опционально)
- `numpy`
- `pandas`
- `matplotlib`
- `scikit-learn`

В продвинутых занятиях могут использоваться дополнительные пакеты — `wfdb`, `pydicom`, `SimpleITK`, `PyTorch`, `FAISS`, `Chroma`, — однако для базовой версии репозитория они не требуются.
